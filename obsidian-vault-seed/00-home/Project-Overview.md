# ProjectLens 项目总览

ProjectLens 是一个以项目为上下文、以飞书协作群为工作现场的项目协作 Agent。

第一阶段聚焦飞书文档、会议纪要、飞书多维表格和 GitHub 的只读接入，并通过 Hermes 返回带依据的项目回答。

## 核心原则

- ProjectLens 负责来源、Evidence、权限、检索和审批。
- Hermes 负责整理、关联、检查和提案。
- Obsidian 负责团队共享阅读、关联、审阅和补充。
