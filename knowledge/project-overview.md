## 项目定位

ProjectLens 是一个以项目为上下文、以飞书协作群为工作现场的通用项目协作 Agent。它帮助业务、产品、研发、测试和管理者基于同一批授权资料理解项目、讨论问题和确认事实。

第一阶段不做四套角色化事实，也不建设 GraphRAG。用户角色只用于权限控制；回答内容由问题、资料和证据决定。

## 当前试点范围

- 飞书文档和会议纪要
- 飞书多维表格
- GitHub Issue、Pull Request、Commit 和必要的代码只读内容
- 被 @ 或明确提问时，通过 Hermes 返回带依据的回答

## 核心回答结构

1. 当前最可信结论
2. 来源、版本和更新时间
3. 当前范围、约定或安排
4. 冲突、过期和不确定性
5. 知识缺口及其影响

## 非目标

Agent 不自动修改原始资料，不自动改变项目状态，不自动分派任务，也不把普通群聊内容直接升级为正式事实。
