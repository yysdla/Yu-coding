六、验收标准

用户可以查询当前正式需求范围。
用户可以查询项目里程碑、负责人和状态。
用户可以查询是否有开发和测试安排。
回答必须包含至少一个来源或明确说明没有证据。
Agent 可以区分会议提议和正式决策。
Agent 可以发现资料冲突和知识缺口。
未授权用户不能读取权限外资料。
Agent 不会执行写入、分配任务或修改状态。

八、回滚方案

当前版本为只读试点资料和检索能力，不会自动写入原始项目资料。

如出现错误回答、权限异常或资料污染，应停止对应来源的同步和检索，并由项目管理员核对源资料后重新启用。
